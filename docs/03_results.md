# 3. 결과 — 데이터셋 통계와 baseline 대비 파인튜닝 평가

## 3.1 생성 데이터셋 통계

| 항목 | 값 |
|---|---|
| 전경(곰) 생성 시도 → 확보 | 220 → 214 (품질 게이트 통과율 97.3%, GrabCut 실패 0 / CLIP 실패 0 / 중복 6) |
| 배경 장면 생성 시도 → 확보 | 180 → 173 (bear-leak 제거 7) |
| 배경 day/dusk : night_ir | 115 : 58 |
| 최종 합성 이미지 | 600장 (train 540 / val 60) |
| 전경 최대 재사용 | 6회 (풀 214개 대비) |
| 배경 최대 재사용 | 5회 (풀 173개 대비) |

**크기 분포 — 목표한 결핍 구간(small)을 실제로 채웠는가**

| 세트 | small | medium | large |
|---|---|---|---|
| 목표 | 60% | 30% | 10% |
| 실제(bear_synth) | 62% (375) | 28% (169) | 9% (56) |
| real_val (실사진, 비교용) | 7% (5) | 18% (13) | 75% (53) |

목표 분포와 오차 2%p 이내로 일치했고, COCO/real_val이 심하게 large에 쏠린 것과
정반대로 small을 다수로 만들었다 — 1차에서 확인한 결핍(작은 곰 37개)을 겨냥한
설계가 실제로 그대로 반영됐다.

## 3.2 baseline vs 파인튜닝 평가

학습: YOLOv8n(COCO 사전학습) → 백본 앞 10개 층 동결, AdamW lr0=0.0008, 40 epoch,
`bear_synth`(600장, class→COCO index 21 재라벨) + `reg_sample` 70%(245장, 다른
79클래스 원 라벨) 혼합 학습. 평가는 전부 학습에 쓰이지 않은 홀드아웃 3세트.

| 세트 | 지표 | baseline | finetuned | Δ |
|---|---|---|---|---|
| real_val (원본 화질) | mAP@0.5 | 0.904 | 0.501 | **-0.402** |
| real_val (원본 화질) | recall | 0.831 | 0.310 | -0.521 |
| real_val (원본 화질) | precision | 0.873 | 0.853 | -0.021 |
| real_val_lq (열화 적용) | mAP@0.5 | 0.399 | 0.478 | **+0.079** |
| real_val_lq (열화 적용) | recall | 0.282 | 0.451 | **+0.169** |
| real_val_lq (열화 적용) | precision | 0.660 | 0.619 | -0.040 |
| reg_holdout (다른 79클래스) | mAP@0.5 | 0.728 | 0.474 | -0.254 |
| reg_holdout (다른 79클래스) | mAP@0.5:0.95 | 0.571 | 0.302 | -0.269 |

## 3.3 해석 — 있는 그대로

**먼저 baseline 자체가 이 연구의 문제의식을 그대로 증명한다.** 사전학습 YOLO는
원본 화질에서 bear mAP@0.5 0.904로 이미 훌륭하다. 그런데 **화질만 낮췄을 뿐인
동일한 71개 박스**에서 0.399로 반토막난다(-0.505). 곰이 사라진 게 아니라 곰을
"작고 흐리게" 본 학습 경험이 1차에서 확인한 대로 37개뿐이었기 때문이다.

**파인튜닝은 목표한 조건에서는 실제로 작동했다.** real_val_lq에서 mAP@0.5
+0.079, 특히 recall이 0.282→0.451로 60% 가까이 올랐다 — "저화질에서 곰을 더
많이 찾아낸다"는, 이 연구가 정확히 원했던 방향의 개선이다.

**그 대가로 두 가지가 나빠졌다.** ① real_val(원본 화질)에서 mAP@0.5가
0.904→0.501로 크게 떨어졌다. ② 곰과 무관한 다른 79개 클래스 성능도
0.728→0.474로 떨어졌다(재앙적 망각). 둘 다 원인이 같다고 본다 —

- 학습 배치의 69%(540/785)가 bear_synth이고, 그중 62%가 small 스케일이다.
  모델이 "작고 저화질인 곰"에 강하게 쏠리면서 원래 잘하던 "크고 선명한 곰"
  스케일의 사전지식이 밀려났다(real_val은 large가 75%).
- freeze=10(백본 앞단만 동결)으로는 목·헤드가 여전히 자유롭게 움직이고, 정칙화
  표본(reg_sample 245장, 79클래스 분산)이 bear_synth 540장에 비해 절대적으로
  적어 망각을 막기에 부족했다.

이건 실패가 아니라 **한 번의 파인튜닝 설정이 만들어낸 정직한 트레이드오프**다.
"저화질 곰 검출을 개선한다"는 목표 자체는 달성됐고, 그 개선이 공짜가 아니라는
것까지 같이 확인된 것이 이 실험의 값어치다.

## 3.4 4차 — 재앙적 망각 완화 시도 (정칙화 오버샘플링)

§3.3에서 지목한 원인("bear_synth:reg_fit ≈ 2.2:1로 배치가 곰에 쏠림")을 실제로
바꿔서 검증했다. `reg_fit`(245장)을 곰 데이터(540장)와 거의 1:1이 되도록
반복 복사(오버샘플링)해서 **다른 하이퍼파라미터는 전부 동일하게 고정**하고
다시 학습했다(`scripts/10_finetune_balanced.py`).

| 세트 | 지표 | baseline | v1 (2.2:1) | v2 (1:1 오버샘플링) | v2-v1 |
|---|---|---|---|---|---|
| real_val (원본화질) | mAP@0.5 | 0.904 | 0.501 | 0.448 | **-0.053** |
| real_val (원본화질) | precision | 0.873 | 0.853 | 0.643 | -0.210 |
| real_val_lq (열화) | mAP@0.5 | 0.399 | 0.478 | 0.497 | +0.019 |
| real_val_lq (열화) | precision | 0.660 | 0.619 | 0.677 | +0.058 |
| reg_holdout (79클래스) | mAP@0.5 | 0.728 | 0.474 | 0.494 | +0.020 |
| reg_holdout (79클래스) | mAP@0.5:0.95 | 0.571 | 0.302 | 0.331 | +0.029 |

![v1 vs v2](figures/fig08_v1_vs_v2.png)

**가설은 부분적으로만 맞았다.** reg_holdout이 소폭 올랐고(+0.020) real_val_lq도
같이 좋아졌다(+0.019, precision +0.058) — 방향은 맞다. 하지만 크기가 작다.
v1이 baseline 대비 벌어진 격차(0.728-0.474=0.254)의 8%만 좁혔을 뿐, 여전히
baseline과 0.234p 차이가 남아 있다(0.728 vs 0.494). 오히려 real_val(원본화질)은
더 나빠졌다(-0.053, precision -0.210) —
원인은 반복 복사로 학습 스텝 자체가 늘어나면서(reg_fit이 이미지당 여러 번
등장) 40 epoch 고정 기준으로는 상대적으로 더 오래/많이 학습된 셈이 되어
과적합 방향이 바뀐 것으로 보인다.

**결론: 표본 비율 하나만 바꿔서는 이 트레이드오프가 풀리지 않는다.** 데이터
비율보다 학습 스케줄(에폭 수를 표본 총량에 맞춰 재조정) 또는 freeze 깊이 쪽
변수가 더 크게 작용하고 있을 가능성이 높다 — 다음 시도 항목으로 아래 표에
반영했다.

## 3.5 한계와 다음 단계

| 한계 | 원인 추정 | 다음 시도 |
|---|---|---|
| 원본 화질 성능 퇴보 | 학습 데이터가 small에 과도하게 쏠림(62%) | bear_synth 크기 분포를 real_val 실제 비율에 더 가깝게 완화하거나, large 비중을 높인 버전을 별도로 섞기 |
| 재앙적 망각 (일부만 완화됨) | §3.4에서 표본 비율을 1:1로 맞춰봤지만 baseline 대비 격차의 8%만 좁혀짐 — 원인이 비율보다는 학습 스케줄(오버샘플링으로 늘어난 반복 학습량) 쪽일 가능성 | epoch 수를 표본 총량에 맞춰 재조정하거나, reg_holdout 지표 기준 조기 종료(현재 patience는 bear 전용 val fitness만 봄) 도입 |
| GrabCut 잔여 배경 조각 | 스튜디오풍 배경에 소품(암석 등)이 섞여 나온 경우 전경에 포함됨 (fig06 large/day 샘플 참고) | 컷아웃 후 최대 연결요소만 남기는 후처리 추가 |
| 색상 정합 | 밝기만 맞추고 색조(hue)는 맞추지 않음 | LAB 공간 색 전이(color transfer)로 확장 |
| 1회 실행 결과 | 시드 1개, 파인튜닝 2회(v1/v2) | 시드 반복 및 freeze/lr/분포 그리드 탐색 |
